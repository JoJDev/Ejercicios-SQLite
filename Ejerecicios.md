# Ejercicios SQL para resolver

Los ejercicios para practicar SQL están en la carpeta *ejercicios* y se han desarrollado teniendo en mente la base de datos SQLite3, con la base de datos incluida en este repositorio ([Chinook.db](base_de_datos/chinook.db)).

## Estructura

Cada tema está en un archivo .sql independiente y puede tener uno o más ejercicios relacionados con el tema, los cuales pueden tener la siguiente estructura:

### Descripción del ejercicio
Instrucciones para realizar el ejercicio en forma de comentario.

### Espacio para realizar el ejercicio
Espacio para realizar el ejercicio. Puede ejecutar los comandos SQL de cada ejercicio uno por uno o todos a la vez ejecutando todo el archivo .sql.

### Resultado esperado
Comentario con el mensaje o resultado esperado al realizar correctamente el ejercicio. Si hay muchos datos como salida, solo se mostrarán 10 filas del resultado esperado.

### Comandos para restaurar la base de datos original
Comandos para restaurar la base de datos original para los siguientes ejercicios. Si no fuera posible la restauración, se pedirá que elimine y cree de nuevo la base de datos original. 

### Más ejercicios con la misma estructura
Si hay más ejercicios del tema a practicar, se encontrarán más abajo en el archivo con la misma estructura antes mencionada.
